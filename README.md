这个项目是“手指游戏”，规则我放在下面了，是我去年假期里闲着没事干写的。它有pvp，pve，eve模式，可以在某个python文件里更改模式，但我忘了具体是哪个文件了。默认运行main，应该是pve模式。别笑，你来你也打不过ai。

规则：想象现在你和你好哥们呆在教师里无聊，又不能说话。于是，你们拿出双手，玩起了手指游戏。一开始，两个人的四只手都是1，你的获胜目标是将你的两只手都变成0。

这个游戏是回合制的。你和兄弟轮流动手指，到你的回合时，你可以选择你左手或右手任意一个手，拿上面的数去加你兄弟左手或右手任意一个手上的数字，然后保留个位数显示在手上。
如果变成了0，那就收回这只手，之后就不能动了，你兄弟也不能加这只变为0的手。

举例：一开始，四个手都是1，我们写做(1, 1), (1, 1)，前面的是你的手，后面的是你兄弟的手。你先开始，将你的左手加上你兄弟的右手，变成：(2, 1), (1, 1)。
到你兄弟了，他将他的左手加上你的左手，变成(2, 1), (3, 1)。
又到你，变成(5, 1), (3, 1)
到兄弟，变成(5, 1), (3, 6)
你：(1, 1), (3, 6) （因为5+6=11，只保留个位数就是1）
......20 years later......
你：(2, 2), (6, 6)
兄弟：(2, 2), (8, 6)
你：(0, 2), (8, 6)
兄弟：(0, 2), (0, 6)
聪明的你心里一算，发现后面变成了无限循环。于是，你们达成了平局！
